Accessibility statement for the Resistor Network Revision app

This accessibility statement applies to the Resistor Network Revision web application used to support revision for resistor network calculations on the RAF Aerospace Engineering Technician course.

This website is run by [name of public body / unit — complete before publishing]. We want as many people as possible to be able to use this website.

How you should be able to use this website

For example, that means you should be able to:

  • change colours, contrast levels and fonts using browser or system settings
  • zoom in up to 200% without the text spilling off the screen
  • navigate most of the website using only a keyboard
  • navigate most of the website using a screen reader (including recent versions of JAWS, NVDA and VoiceOver)

We’ve also made the website text as simple as possible to understand, noting that the content is technical electrical principles aligned to the course.

AbilityNet has advice on making your device easier to use if you have a disability.

Technical information about this website’s accessibility

Compliance status

This website is partially compliant with the Web Content Accessibility Guidelines version 2.2 AA standard, due to the non-compliances listed below.

Non-accessible content

Non-compliance with the accessibility regulations

  • Mathematical notation via MathJax may be announced unclearly by some assistive technologies (WCAG 1.1.1, 1.3.1).
  • Circuit diagrams are drawn on a canvas. Text alternatives describe the network layout and labelled values; complex multi-resistor networks may still need more detail for some users (WCAG 1.1.1).
  • Training notes open linked PDF documents. Accessibility of those PDFs depends on how each file was produced and may not meet AA (WCAG 1.1.1, 2.4.5).

Content not within the scope of the accessibility regulations

  • Third-party libraries loaded from a CDN (for example MathJax and Bootstrap CSS) are not fully under our control.

What we’re doing to improve accessibility

  • Visible keyboard focus indicators and a skip link on the main app
  • Topic controls implemented as buttons with clear labels
  • Text alternatives for resistor network diagrams that include live component values
  • A dedicated control to open the separate teacher solution window
  • Background colour options that also apply to the separate solution window

We plan to refine diagram descriptions where feedback shows they are unclear, and to review MathJax / PDF accessibility as course materials are updated.
